# Larkin releases

Release builds of the Larkin macOS app and the Sparkle appcast that keeps installed copies up to date.

- Download: the latest `Larkin-<version>.dmg` under [Releases](../../releases). Requires macOS 26.
- Updates: Larkin checks `appcast.xml` in this repository; use **Check for Updates…** in the menu bar item.
- Every update archive carries an EdDSA signature that the app verifies before installing.

This repository holds release assets only.
